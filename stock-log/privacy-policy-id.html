Kebijakan Privasi

Halaman ini merupakan terjemahan dari naskah asli berbahasa Jepang (プライバシーポリシー). Apabila terdapat perbedaan di antara keduanya, versi bahasa Jepang yang berlaku.

Kebijakan ini menjelaskan cara aplikasi "Stock Log" (nama dalam bahasa Jepang: かぶログ; "Aplikasi") menangani informasi.
Tanggal berlaku: 15 November 2026

1. Tempat penyimpanan catatan Anda

Catatan yang Anda masukkan atau impor ke dalam Aplikasi (rekening, efek, transaksi, dividen, manfaat pemegang saham, alasan, memo, dll.) hanya disimpan di perangkat Anda dan dienkripsi di perangkat. Operator tidak memiliki server, dan operator tidak pernah menerima atau melihat catatan Anda.

2. Informasi yang tidak kami kumpulkan

Aplikasi tidak menerima nama, alamat email, ID login atau kata sandi perusahaan sekuritas, maupun nomor rekening Anda. Tidak ada pendaftaran akun. Aplikasi tidak mengukur perilaku Anda untuk keperluan iklan atau analitik, dan tidak terhubung ke internet untuk memperoleh data pasar seperti harga saham.

3. Informasi yang dikirim ke layanan pihak ketiga

  • Sentry (Functional Software, Inc.): Untuk menyelidiki bug, saat terjadi kesalahan, Aplikasi mengirimkan jenis dan lokasi kesalahan, jenis perangkat dan OS, serta versi aplikasi. Isi catatan Anda (efek, jumlah, memo, dll.) tidak dikirim.
  • RevenueCat (RevenueCat, Inc.): Untuk memeriksa status paket berbayar, Aplikasi mengirimkan informasi pembelian dan pengenal anonim yang dibuat untuk setiap perangkat.
  • Apple (App Store) / Google (Google Play): Pembelian dan pembayaran paket berbayar dilakukan melalui masing-masing toko, dan kebijakan privasi masing-masing perusahaan berlaku.

4. Impor file riwayat transaksi

Saat Anda mengimpor CSV, Aplikasi membaca file yang Anda pilih di perangkat Anda dan menyimpannya sebagai catatan. Aplikasi tidak menyimpan file itu sendiri maupun namanya, dan menghapus file sementara di perangkat setelah membacanya. Isi file tidak pernah dikirim ke luar perangkat.

5. Autentikasi biometrik (kunci aplikasi)

Kunci aplikasi menggunakan Face ID, sidik jari, atau kode sandi perangkat Anda. Informasi biometrik dikelola oleh sistem operasi perangkat, dan Aplikasi tidak pernah menerimanya.

6. Cadangan dan ekspor

Cadangan terenkripsi dibuat sebagai file yang dienkripsi dengan kata sandi yang Anda pilih, dan Anda sendiri yang memilih tempat penyimpanannya. Kata sandi tersebut tidak disimpan. File yang dibuat melalui ekspor CSV tidak dienkripsi. Anda bertanggung jawab atas pengelolaan file di tempat Anda menyimpannya.

7. Penghapusan data

Karena catatan Anda hanya ada di perangkat Anda, menghapus Aplikasi juga akan menghapus catatan Anda (kecuali jika catatan tersebut dipulihkan dari cadangan perangkat). Operator tidak menyimpan catatan apa pun, sehingga Anda tidak perlu meminta operator untuk menghapusnya.

8. Privasi anak-anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia 13 tahun.

9. Permintaan terkait data pribadi

Operator tidak menyimpan catatan Anda, tetapi pertanyaan dan permintaan terkait kebijakan ini diterima melalui kontak di bawah ini.

10. Langkah-langkah keamanan

Aplikasi mengenkripsi catatan di perangkat, membatasi data yang dikirim ke luar perangkat seminimal mungkin (bagian 3), dan menghapus isi catatan dari laporan kesalahan.

11. Penafian

Aplikasi ini ditujukan untuk mencatat dan meninjau kembali transaksi Anda sendiri dan tidak memberikan nasihat investasi. Angka yang ditampilkan dihitung berdasarkan catatan yang Anda masukkan atau impor, dan keakuratannya tidak dijamin. Untuk keperluan pelaporan pajak dan keperluan serupa, harap periksa laporan transaksi dan dokumen lain dari perusahaan sekuritas Anda.

12. Perubahan kebijakan ini

Apabila kebijakan ini berubah, perubahan tersebut akan diumumkan di halaman ini.
