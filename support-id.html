Pertanyaan yang Sering Diajukan

T. Di mana data yang saya rekam disimpan?
J. Semua data disimpan secara lokal di perangkat Anda. Data tersebut tidak pernah dikirim secara otomatis ke server eksternal. Saat berpindah perangkat, gunakan fitur backup JSON di Pengaturan untuk mengekspor data Anda, lalu impor di perangkat baru Anda.

T. Bagaimana cara membatalkan langganan saya?
J. Pengaturan → Apple ID → Langganan → FX Trade Journal.

T. Pembelian saya tidak muncul.
J. Coba tombol "Pulihkan Pembelian" di Aplikasi. Jika masalah berlanjut, silakan hubungi kami dengan detail perangkat dan versi OS Anda.

T. Bisakah saya mengimpor riwayat trade MT4/MT5?
J. Ya — buka Pengaturan untuk mengimpor file CSV format MT4. Format bervariasi antar broker, jadi beberapa file mungkin tidak dapat diimpor dengan benar.
