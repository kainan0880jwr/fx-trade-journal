Pertanyaan yang Sering Diajukan

T. Di mana data yang saya rekam disimpan?
J. Catatan transaksi dan gambar chart Anda disimpan secara lokal di perangkat Anda dan tidak pernah dikirim ke server eksternal. Saat berpindah perangkat, gunakan fitur backup JSON di Pengaturan untuk mengekspor data Anda, lalu impor di perangkat baru Anda. Perlu diketahui, laporan crash dan informasi penggunaan terbatas dikirim ke layanan pihak ketiga untuk mendeteksi bug dan memproses pembelian dalam aplikasi — lihat Kebijakan Privasi kami untuk detailnya.

T. Bagaimana cara membatalkan langganan saya?
J. iOS: Pengaturan → Apple ID → Langganan / Android: Google Play Store → Profil → Pembayaran & langganan → Langganan → FX Trade Journal.

T. Pembelian saya tidak muncul.
J. Coba tombol "Pulihkan Pembelian" di Aplikasi. Jika masalah berlanjut, silakan hubungi kami dengan detail perangkat dan versi OS Anda.

T. Bagaimana cara mengimpor riwayat MT4/MT5?
J. Di komputer, klik kanan tab Account History di MT4 atau History di MT5 lalu simpan laporan (.htm di MT4, .html di MT5). Kirim file ke ponsel lewat AirDrop, iCloud Drive, atau email, lalu pilih di aplikasi melalui Pengaturan → Impor MT4/MT5. CSV berformat MT4/MT5 juga bisa diimpor. Format sebagian broker mungkin tidak dapat dibaca. Memerlukan versi terbaru aplikasi.

T. Bagaimana cara meminta pengembalian dana?
J. Untuk App Store, buka reportaproblem.apple.com. Untuk Google Play: Google Play Store → Profil → Pembayaran & langganan → Anggaran & histori, lalu pilih pembelian. Pengembalian dana mengikuti kebijakan masing-masing toko; kami tidak dapat mengembalikan dana secara langsung.

T. Saya lupa kata sandi backup.
J. Backup yang dienkripsi tidak dapat dipulihkan tanpa kata sandinya. Kata sandi tidak disimpan di perangkat maupun oleh kami, jadi kami tidak dapat mencarinya atau mengatur ulangnya. Jika perangkat lama masih ada, buat backup baru dengan kata sandi baru.
